# Tsuzuri の図の書き方

利用者に図を頼まれたら、Tsuzuri の図エディタの図として書く。図は JSON で書き、画像（PNG）は Tsuzuri が作る。
利用者は本文の図を押すと、図エディタで開いて手直しできる。

## 手順

1. 図のファイルを、文書の添付フォルダ（文書の隣の `.文書名` フォルダ）に Write で書く。
   名前は `図 yyyy-MM-dd HHmmss.json`（今の日時。例: `図 2026-11-01 153000.json`）。同じ名前があれば末尾に ` (2)` などを付ける。
2. 見ているページの、頼まれた場所（断りが無ければカーソルの行）に、画像へのリンクを書く。名前に空白があるので `<>` で囲む:
   `![図 2026-11-01 153000](<図 2026-11-01 153000.png>)`
3. **.png は書かない。** .json を書くと、Tsuzuri がすぐ .png を作り、本文に表示する。
   作れなかったときは、何がいけないかがツールの結果のあとに知らされるので、.json を直して書き直す。

今ある図を直すときは、その .json を読んで書き換える（.png は Tsuzuri が作り直す）。図形の `id` は変えない。

## ファイルの形

```json
{
  "kind": "markdown-editor-drawing",
  "version": 1,
  "boardX": 0, "boardY": 0, "boardWidth": 160, "boardHeight": 90,
  "unit": 1,
  "shapes": [
    { "type": "rect", "id": "s1", "x1": 10, "y1": 30, "x2": 50, "y2": 50, "text": "入力", "fill": "#DCE8F8" },
    { "type": "rect", "id": "s2", "x1": 100, "y1": 30, "x2": 140, "y2": 50, "text": "出力" },
    { "type": "line", "id": "s3", "x1": 50, "y1": 40, "x2": 100, "y2": 40,
      "startShape": "s1", "startU": 1, "startV": 0.5, "endShape": "s2", "endU": 0, "endV": 0.5 },
    { "type": "text", "id": "s4", "x1": 10, "y1": 8, "text": "処理の流れ", "size": 12 }
  ]
}
```

- `kind`・`version` はこの値のまま必ず書く。
- 長さはすべて **mm**。座標は左上が原点で、**y は下向き**。
- ボード（`boardX`・`boardY`・`boardWidth`・`boardHeight`）が画像にする範囲。外に出た図形は切れる。
  画像は幅 160mm に縮めて（広げて）本文に出るので、**幅は 160 にして、高さを中身に合わせる**のがよい（`unit` は 1）。
  高さは幅の 10 倍まで。
- `unit` は、文字の大きさ・線の太さの基準（紙の 1mm が図の何 mm か）。幅 160 のボードなら 1。
  実寸の大きな物（例: 幅 2000mm）を描くときは、ボードをその大きさにして、`unit` を `ボードの幅 ÷ 160` にする（文字・線が紙の上で同じ大きさに見える）。
- `id` は図の中で重ならない文字列（`s1`, `s2`, …）。線をつなぐときに使う。

## 図形（`type`）

| type | 位置 | ほかの欄 |
|---|---|---|
| `rect`（四角） | `x1,y1` と `x2,y2` が向かい合う角 | `text`（中の文字。真ん中にそろい、幅で折り返す）・`size`（pt。既定 10.5）・`fill`・`lineWidth` |
| `ellipse`（丸） | 同じ（その四角に収まる楕円） | 四角と同じ |
| `text`（文字） | `x1,y1` が左上（`x2,y2` は使わない） | `text`（改行は `\n`）・`size`（pt。既定 10.5） |
| `line`（直線） | `x1,y1` が始点、`x2,y2` が終点 | `points`（途中の折れ目。`[x, y, x, y, …]` を始点の側から）・`lineWidth`・つなぎ |
| `dimension`（寸法線） | `x1,y1` から `x2,y2` までの長さを測る | `offset`（測る2点から寸法線までの離れ mm。始点から終点へ向かって左が正。左から右へ測るなら上が正）・`size`（数値の pt。既定 9） |

- 寸法線の数値は、2点の長さ（mm）が自動で入る。好きな文字にはできない。
- 線に矢印は付けられない（寸法線の矢印だけ）。向きを示したいときは、文字で補う。
- `fill`（塗り）は次の色だけ: 白 `#FFFFFF`・灰 `#E4E6EA`・青 `#DCE8F8`・緑 `#DDF0DC`・黄 `#FFF3C4`・赤 `#FBDEDE`。塗らないなら書かない。
  塗った図形は、それより前に書いた図形を隠す（後ろに描きたいものは前に書く）。
- `lineWidth`（線の太さ mm）の既定は 0.25。強調したい線だけ 0.5 などにする。
- 線は黒、字は黒の Yu Gothic UI。全角1文字の幅は、おおよそ `size × 0.35` mm（10.5pt なら約 3.7mm）。四角は文字が収まる大きさにする。
- `image`（貼った画像）は書かない（図エディタで貼るもの）。

## 線をつなぐ

線（`line`・`dimension`）の端は、ほかの図形につないでおける。つないだ図形を図エディタで動かすと、線の端が付いてくる。

- `startShape`・`endShape`: つなぐ相手の `id`。
- `startU`・`startV`（`endU`・`endV`）: 相手のどこにつなぐか。四角・丸なら、相手の枠の中の割合（0〜1。左上が 0,0、右の辺の真ん中は 1, 0.5）。
  相手が線なら、`U` は始点から終点への道のりの割合、`V` は -1。
- つないだ端の `x1,y1`（`x2,y2`）は、Tsuzuri が相手の位置から計算し直す。それでも、おおよそ合った値を書いておく。

## 描き方のこつ

- 先に全体の配置（何をどこに置くか）を決めてから座標を書く。四角どうしは 10mm 以上あける。
- 文字は四角の中に入れる（`rect` の `text`）。説明の文字は `text` で置く。
- 細かすぎる図にしない。本文では幅 160mm で表示される。
